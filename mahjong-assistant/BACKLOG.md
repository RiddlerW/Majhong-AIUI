# 麻将助手 - 待更新功能清单

## 算法优化

### P0 - 核心算法增强

- [ ] **一进听计算**：当14张牌无法直接听牌时，计算打出每张牌后离听牌的距离（一进听/二进听），推荐牌效最优的打法
- [ ] **有效进张数排序**：出牌建议排序应优先按"有效进张总数"（听牌数 × 每张听牌的剩余张数之和），而非单纯按听牌种数排序
- [ ] **七对子胡牌判断**：支持七对子牌型的胡牌/听牌/建议计算
- [ ] **碰/杠后手牌数校验**：有碰杠时手牌总数的校验逻辑需更细致（当前公式 `(4-meldCount)*3+2` 在某些边界情况下可能不准确）

### P1 - 牌效与进阶分析

- [ ] **多进听计算**：支持二进听及更深层的牌效分析，评估每张牌对整体牌型的贡献
- [ ] **向听数计算**：实现向听数（shanten number）算法，量化当前手牌离听牌的距离
- [ ] **牌效评分**：为每个出牌建议附加牌效评分，综合考虑进张面、改良空间、防守等因素
- [ ] **定缺花色残留检查**：当手牌中仍有定缺花色的牌时，应提示"定缺未清"并优先建议打掉

### P2 - 番型与规则

- [ ] **血战到底番型计算**：平胡、对对胡、清一色、七对、龙七对、清七对、清龙七对、金钩钓等
- [ ] **血流成河番型计算**：在血战基础上增加加番规则（根、杠上开花等）
- [ ] **国标麻将番型计算**：81种番型，8番起胡（这是最复杂的部分，可能需要分阶段实现）
- [ ] **番型影响出牌建议**：当有多种出牌选择时，考虑番型收益（如清一色方向 vs 平胡方向）

### P3 - 算法架构

- [ ] **算法提取到 lib/mahjong-analyzer.js**：将页面内嵌的算法提取为独立模块，AIUI页面和预览页面共用
- [ ] **向听数算法替代当前暴力枚举**：用shanten算法作为核心，听牌/建议都基于向听数计算，更高效更准确
- [ ] **算法性能优化**：缓存中间结果、剪枝优化，确保在眼镜端设备上流畅运行
